# 语法漫游 · Grammar Atlas

这是整理好的 GitHub 项目源码，包含刚更新的手机、平板、电脑三端自适应版本。

## 从哪里开始

要放进已有项目，先看 [导入 GitHub 项目说明](IMPORT_TO_GITHUB.md)。要新建独立的网站仓库，把本目录内的文件上传到仓库根目录即可。

## 已包含的内容

- 11 个语法主题、53 个核心知识点、212 段分步讲解。
- 106 个双语例句、159 道练习及即时解析。
- 导图展开、拖动、缩放、全屏、缩略图定位和比例调节。
- 讲解、例句朗读、选择题、填空题、错题重练。
- 收藏、笔记、学习进度，以及进度备份的导出和导入。
- 教材名称和单元索引。中文讲解、例句及练习均为新编。

## 语法分类

目录、总导图、学习路径和练习筛选均按以下顺序展示：

1. 词性
2. 句式
3. 时态与语态
4. 主谓一致
5. 状语从句
6. 定语从句
7. 名词性从句
8. 非谓语动词
9. 虚拟语气
10. 倒装
11. 强调

知识点按实际内容归类：被动语态归入“时态与语态”，真实条件句归入“状语从句”，并列连接归入“句式”。原先合并的倒装、强调与 there be 已拆开；普通 should 用法与建议类虚拟从句也分别讲解。

原有知识点和练习的标识保留，拆分后旧错题会自动关联到新的所属知识点，已有收藏、笔记和答题记录可继续使用。主题数量、题目总数和掌握比例由内容自动计算。

完整分类框架可查看 [十一类语法思维导图](grammar-mindmaps.md)。

## 三端布局

| 设备 | 布局 |
| --- | --- |
| 电脑，至少 1280px | 目录、导图、讲解三栏并排 |
| 平板及小窗口，768–1279px | 左上角按钮切换完整目录和窄图标栏；导图自动适应剩余宽度，讲解按需打开 |
| 手机，小于 768px | 导图自动占满导航上方的空间，紧凑的纵向分支配底部导航和阅读面板 |

界面采用蓝白为主的低饱和配色，仅保留知识点与操作信息。平板目录默认收起，展开和收起均可继续操作主界面，按 Esc 也可收起目录；横竖屏切换时保留本次会话的目录状态。

屏幕宽度或可用高度变化时会重新安排导图。手机阅读正文和输入框采用 16px 字号，讲解区可以单独滚动。

## 本地运行

安装 Node.js 20 或更高版本后，在本目录打开终端：

```sh
npm run dev
```

浏览器打开终端显示的网址即可。本项目使用原生 HTML、CSS、JavaScript，运行脚本只用 Node.js 内置模块，无需安装第三方依赖。

```sh
npm run check
npm run build
npm run preview
```

`check` 检查分类顺序、题库、旧错题归属、资源路径和 648 组导图布局。`build` 把可部署的 6 个静态文件复制到 `dist/`；`preview` 预览该目录。原始网页文件也可以直接静态托管，构建为可选步骤。

## 继续开发

语法讲解、例句或练习集中编辑 `content.js`。保留每个知识点的 `id`，已有收藏和学习记录可以继续对应。增加知识点时，也要更新检查脚本的数量预期。

调整布局时优先编辑 `responsive.css`。每个知识点保留 4 段讲解、2 个例句和 3 道练习。

## 数据和朗读

进度、错题、收藏和笔记保存在访问者当前浏览器中。切换设备或域名前，可导出备份，再在新设备或新域名导入。不同设备不会自动同步。

朗读使用设备提供的英语语音，能否播放及音色由浏览器和设备决定。
