# English Grammar · 语法图谱

原生 HTML、CSS、JavaScript 英语学习网站。首页展示总图谱与左侧可收缩边栏，使用更鲜明的蓝白配色和高对比文字。

## 学习流程

总地图 → 模块子地图 → 知识卡片 → 下一级知识点 → 对应练习。

- 总图中心为 **English Grammar**，外层依次为词法、句法、时态、语态、从句、非谓语、主谓一致、倒装、虚拟语气、写作常见错误。
- 词法子地图包含名词、代词、冠词、形容词、副词、介词、连词、动词、数词、感叹词。
- 知识卡片包含定义、分类、例句、用法、易错点、下一级知识点和小练习。名词卡片可继续进入分类、可数与不可数、单复数、所有格。
- 电脑与平板采用图谱和讲解左右分屏；手机竖屏采用上下分屏，横屏优先左右分屏。拖动蓝色分隔手柄可调整两边大小，比例会保存在当前浏览器；双击恢复默认，方向键微调。卡片右上角可切换全屏阅读。点击地图中心返回上一级，也可使用卡片面包屑和浏览器前进、后退。
- 图谱支持拖动、滚轮、双指缩放和键盘操作；“适应画面”在侧边栏中。

当前包含 **10 个模块、31 张主题卡片、135 个课程知识点、279 个双语例句、405 道练习**。课程保留4段原始步骤与3道题，展示讲解分成基础步骤和可展开的补充说明；每课至少有2个双语例句。完整层级见 [语法图谱框架](grammar-mindmaps.md)。

## 零基础阅读方式

所有135课与31张概览卡片先用白话讲意思，再看日常短句与用法。279个课程例句平均约5.3词，最长11词，其中277句不超过10词，并配中文意思和短说明。

基础内容直接显示；复杂例外放在“再了解一点”，结构公式放在“看结构写法”，均默认收起。主语、宾语、分词等43个常用术语可点开查看白话解释和短例句；做题时也能使用，不会丢失当前答案。收藏或标记已学后，会保留已展开的补充内容和阅读位置。

## 动画讲解

166 张知识卡片均提供原创逐步动画，共 623 步，包括 66 个时间轴场景。词块会按知识点移动、组合、替换和变形，配简单英文与中文说明；名词分类进入分类盒，句型展示词序和组成，从句展示重复部分的替换，时态展示动作与参照时间。

动画默认静止，用户点击播放后才开始；支持暂停、上一步/下一步、重播、步骤滑条、键盘方向键及 0.75×/1×/1.5× 速度。滚出动画、打开弹窗、切走页面或关闭卡片时停止播放。窄卡片提供全屏入口，减少动态效果偏好下仍可静态逐步学习。收藏和标记已学后的当前步骤保留，播放本身不标记学会。编排与维护说明见 [动画说明](ANIMATIONS.md)。

## 视频讲解

部分知识卡片提供匹配该知识点的视频链接，显示平台、作者和学习提示，点击后在新标签页打开。有匹配视频时才显示“视频讲解”与顶部“视频”定位入口。资源按知识点单独配置，不把总课程重复挂到每张卡片；未匹配的卡片继续保持简洁。

视频只作为外部补充，学习记录仍由站内阅读和练习控制。链接来源、知识点映射与核对范围见 [视频资源记录](VIDEO_SOURCES.md)。

## 继续深入分类

“名词 → 名词的分类”可继续展开专有名词、普通名词与具体/抽象辨析；普通名词再展开个体、集体、物质、抽象名词。可数性、复数变化和所有格也有各自的下级卡片。分类标签可直接点击，卡片、地图与面包屑同步深入。

代词、冠词、动词、形容词、副词、介词、连词，以及状语从句、关系词、名词性从句、虚拟条件句新增独立细分课。保留原91课及原273题标识；新课各有4段讲解、2个例句、3道练习和2组纠错。

## 侧边栏

电脑默认展开，点击左上角收起后完全隐藏，内容恢复全宽；展开状态会保存在当前浏览器。手机和平板默认收起，以抽屉方式展开，选择页面、点击遮罩或按 Esc 后收起。收起后通过左上角按钮重新展开。

左侧可收缩边栏提供总地图、练习中心、知识星云、游戏四个页面，以及搜索、收藏与笔记、记录备份、适应画面和操作说明。

**知识星云**将 31 张主题卡片和 135 个课程知识点呈现为 **166 个知识节点**，加上 **10 个模块枢纽，共 176 个点**。**441 条真实关系**连接上下级知识与关联内容，其中 179 条为上下级关系，262 条为知识关联，形成可以跨模块探索的关系网络。同一知识点在不同地图中出现时共用一个节点。

星点可拖拽，空白处可平移，支持缩放、适应画面和 Aa 标签显隐。点击模块枢纽聚焦模块及其跨模块邻居，点击知识星点打开讲解。点击“已学会，点亮星星”，或答对某个具体知识点的全部题目，对应节点便会以金色发光。手机竖屏按画布比例重新布局，标签随空间与缩放调整；打开讲解后仍可拖动分隔手柄调整图谱与卡片大小。

**练习中心**支持按模块或具体知识点筛选、选择题、填空题、即时解析和错题重练。答题时可随时打开知识卡片，关闭后继续当前题目。

## 游戏

游戏中心现已接入用户提供的**词性积木拖拽游戏**，以独立游戏目录组织，方便后续添加其他游戏。

- **50 个不同关卡，5 个阶段**：句子起步、修饰与关系、连接与数量、情绪与复合句、长句挑战。
- 从 “Birds fly.” 等短句过渡到含从句的长句，词性选项从 2 类逐步增加到全部十大词类。
- 保留词性形状积木玩法，统一为低饱和蓝、绿、灰紫、米金配色。手机可拖拽，也可先点词性再点空格；同类积木可重复使用。
- 支持检查答案、错误定位、词性提示、逐词解析、撤销、重置、选关和继续下一关。
- 一次检查全对获得 3 星，两次获得 2 星，之后获得 1 星；每关保留最高星级。通关记录与学习记录一同保存和备份。

## 本地运行

需要 Node.js 20 或更高版本，无需安装第三方依赖。

```sh
npm run dev
```

浏览器打开终端显示的网址即可。

```sh
npm run check
npm run build
npm run preview
```

`check` 检查图谱、卡片、题库、50 关游戏、学习记录兼容性、资源路径和 全部带下级节点的导图布局。`build` 将 33 个静态文件复制到 `dist/`；`preview` 预览构建结果。源码也可以直接静态托管，所有资源均使用相对路径，支持 GitHub Pages 项目子目录。

## 内容维护与数据

本轮参考用户提供的《英语语法知识体系详解》，覆盖 21 章知识框架；补上构词法、短语、完整时态框架、句子类型、特殊被动、形式 it、省略与长句分析等内容。卡片新增“原句 → 改写 → 原因”，时态卡片提供可折叠对照表。章节对应关系见 [内容参考与覆盖范围](CURRICULUM_SOURCES.md)。

编辑知识点时保留原有 ID；已有知识点的展示详解维护在 `lesson-details-*.js`，新知识点维护在 `content-additions.js`，主题卡片与层级维护在 `atlas.js`。原有 53 个知识点和 159 道题的标识保留，旧收藏、笔记、答题和错题记录继续可用，拆分过的错题归属会自动修正。

游戏句子和逐词词性标注集中在 `games-content.js`，界面逻辑位于 `games.js`。词性按词在当前句子中的实际作用判断；助动词和情态动词归入动词，基数词和序数词归入数词。

记录保存在当前浏览器，备份格式保持 `grammar-atlas` / `schema: 1`，并增加主题学习及游戏字段。导入旧版备份会合并学习、答题、错题、收藏、笔记和通关记录，重复导入不会叠加题次。跨设备、跨域名使用时需要手动导出和导入。

朗读由设备的英语语音提供。网页讲解、例句和练习均为学习用途重新编写。接入其他项目的步骤见 [导入说明](IMPORT_TO_GITHUB.md)。
