# 语法漫游 · Grammar Atlas

这是整理好的 GitHub 项目源码，包含刚更新的手机、平板、电脑三端自适应版本。

## 从哪里开始

要放进已有项目，先看 [导入 GitHub 项目说明](IMPORT_TO_GITHUB.md)。要新建独立的网站仓库，把本目录内的文件上传到仓库根目录即可。

## 已包含的内容

- 10 个语法主题、50 个核心知识点、200 段分步讲解。
- 100 个双语例句、150 道练习及即时解析。
- 导图展开、拖动、缩放、全屏、缩略图定位和比例调节。
- 讲解、例句朗读、选择题、填空题、错题重练。
- 收藏、笔记、学习进度，以及进度备份的导出和导入。
- 教材名称和单元索引。中文讲解、例句及练习均为新编。

## 三端布局

| 设备 | 布局 |
| --- | --- |
| 电脑，至少 1280px | 目录、导图、讲解三栏并排 |
| 平板及小窗口，768–1279px | 导图配可收起的侧边讲解；竖屏采用目录抽屉 |
| 手机，小于 768px | 纵向分支导图、底部导航和大字号阅读面板 |

横竖屏切换会重新安排导图。手机阅读正文和输入框采用 16px 字号，讲解区可以单独滚动。

## 本地运行

安装 Node.js 20 或更高版本后，在本目录打开终端：

```sh
npm run dev
```

浏览器打开终端显示的网址即可。本项目使用原生 HTML、CSS、JavaScript，运行脚本只用 Node.js 内置模块，无需安装第三方依赖。

```sh
npm run check
npm run build
npm run preview
```

`check` 检查题库、资源路径和 594 组导图比例。`build` 把可部署的 6 个静态文件复制到 `dist/`；`preview` 预览该目录。原始网页文件也可以直接静态托管，构建为可选步骤。

## 继续开发

语法讲解、例句或练习集中编辑 `content.js`。保留每个知识点的 `id`，已有收藏和学习记录可以继续对应。增加知识点时，也要更新检查脚本的数量预期。

调整布局时优先编辑 `responsive.css`。每个知识点保留 4 段讲解、2 个例句和 3 道练习。

## 数据和朗读

进度、错题、收藏和笔记保存在访问者当前浏览器中。切换设备或域名前，可导出备份，再在新设备或新域名导入。不同设备不会自动同步。

朗读使用设备提供的英语语音，能否播放及音色由浏览器和设备决定。
